amux

Agent Multiplexer — run AI coding agents in persistent, per-directory tmux sessions. One command to start, one command to resume.

$ brew install xiaoxiunique/amux/amux
ghostty — ~/projects/myapp
$ amux init
Installed shell aliases into ~/.zshrc
Installed tmux keybindings into ~/.tmux.conf.local
Installed Ghostty keybindings into ~/Library/.../ghostty/config

$ cc # launches Claude Code in a tmux session
Attaching to session cc_myapp_1a2b3c4d...

# detach with Ctrl-b d, come back any time:
$ cc # resumes the exact same session

$ cx # Codex gets its own session, same dir

$ amux ls
SESSION AGENT
cc_myapp_1a2b3c4d claude
cx_myapp_7e8f9a0b codex
$

Features

Everything you need to manage AI coding agents across projects.

🔁

Persistent Sessions

Each agent gets a deterministic tmux session keyed to the directory. Resume exactly where you left off.

⌨️

Session Switcher

Press Shift+Cmd+O in Ghostty to pop up an fzf selector. Switch any pane to any agent session instantly.

🖥️

TUI Session Manager

Run amux for an interactive picker. Filter, attach, kill, or start new agent sessions with vim keys.

🔧

Custom Agents

Built-in Claude Code & Codex. Add Gemini, Aider, or any CLI agent via a simple TOML config.

📂

Per-Directory Isolation

Same agent + same directory = same session. Different directories are fully isolated. No collisions.

⚡

Zero Overhead

Single Rust binary. No daemon, no background process. Just a thin wrapper around tmux.

Install

Two commands. Under a minute.

terminal
# install via Homebrew
$ brew tap xiaoxiunique/amux
$ brew install amux

# set up aliases + keybindings
$ amux init

# reload shell and go
$ source ~/.zshrc
$ cc # Claude Code is running ✓
or build from source
$ cargo install --git https://github.com/xiaoxiunique/amux
$ amux init

Commands

Simple CLI, no surprises.

terminal
amux run <agent> # launch or reattach agent in cwd
amux init # install aliases + keybindings
amux ls # list managed sessions
amux kill <name> # kill a session
amux config # show resolved config
amux # open TUI session selector

Config

Built-in agents work out of the box. Add your own in TOML.

~/.config/amux/config.toml
# Add a custom agent [[agent]] name = "gemini" alias = "cg" command = ["gemini", "chat"] [[agent]] name = "aider" alias = "ca" command = ["aider"]
built-in agents
# These work with no config: cc → claude --dangerously-skip-permissions cx → codex --yolo # Override by adding an [[agent]] # with the same name. # New names are appended. # Re-run `amux init` to update aliases.

How It Works

Deterministic session naming. No magic.

session naming
# Session name = <alias>_<dirslug>_<sha256[:8]> ~/projects/myapp $ cc → session: cc_myapp_1a2b3c4d ~/projects/myapp $ cx → session: cx_myapp_7e8f9a0b ~/projects/server $ cc → session: cc_server_e5f6a7b8 # Same agent + same directory = same session, always. # SHA-256 of the absolute path guarantees no collisions.
