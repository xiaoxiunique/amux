# AGENTS.md

Single Rust binary crate (`amux`), no workspace. One process is both the CLI
(tmux/rmux session manager) and the `serve` HTTP/WS daemon. Entry point
`src/main.rs` matches on the clap `Command` enum and delegates to
`src/commands/*`; plain `amux` launches the TUI (`src/tui.rs`).

## Build / test / lint

```bash
cargo build                     # debug
cargo build --release
cargo test                      # all tests
cargo test -- <name>            # one test (substring match)
cargo clippy                    # lint (NOT enforced in CI)
cargo fmt                       # format (NOT enforced in CI)
cargo build --features full     # macOS-only host extras; CI builds this only on macos-latest
```

- CI (`.github/workflows/ci.yml`) runs only `cargo build` + `cargo test` on
  ubuntu/macos/windows. **Windows is a supported target** — keep unix-only code
  behind `#[cfg(unix)]`, or CI breaks.
- Tests are inline `#[cfg(test)] mod tests`. There are no dev-dependencies;
  `tempfile` is a regular dep. Tests must not require a real rmux/tmux — the
  multiplexer round-trip tests self-skip when none is installed.
- Release: pushing a `v*` tag runs `.github/workflows/release.yml`, which builds
  binaries and rewrites the Homebrew tap formula. Version lives in `Cargo.toml`.

## Test isolation gotcha

`HOME`, `AMUX_DB_PATH` and `AMUX_STATE_DIR` are process-global; two tests that
redirect them under the parallel runner clobber each other. Any test that reads
or sets them must hold `crate::test_home::lock()` (`src/main.rs`), and tests
needing a throwaway metadata DB should use `crate::test_home::scratch_db()`.
`store.rs` caches its connection keyed by `AMUX_DB_PATH`.

## Non-obvious architecture

- **Built-in agents** (`src/config.rs`) are `claude/cc`, `codex/cx`,
  `opencode/oc`, `pi/p` — not just claude/codex (README/CLAUDE.md are stale).
  The server keeps a *separate* hardcoded launch-command list in
  `src/serve/server.rs` (`agent_launch_command`) that must stay in sync with it.
- **Session naming** (`src/session.rs`): `<alias>_<slug>_<hash8>` where hash8 is
  the first 8 hex of SHA-256 of the canonicalized abs path; `amux new` appends
  `-<suffix>`.
- **Metadata is one SQLite DB now** (`src/store.rs`): `~/.amux/amux.db` (WAL),
  auto-migrating the old JSON files (`project-history.json`,
  `session-labels.json`, `session-ids.json`). `scripts/backfill-session-ids.py`
  still writes the pre-SQLite JSON path and is stale.
- **`src/tmux.rs`** (name is legacy) drives the multiplexer as a subprocess and
  defaults to **rmux**; `AMUX_MUX=tmux` falls back to tmux.
- **`src/serve/server.rs`** (~5.6k lines) is the entire HTTP/WS server + web UI;
  route table is near the top of `run_server`. The `full` feature adds the
  macOS control-center / usage / APNs routes in `src/serve/full/`.
- **`webui/`** is a *prebuilt* Flutter web bundle embedded at compile time via
  `include_dir!` in `src/serve/server.rs`. There are no Dart sources in this
  repo — do not hand-edit it.
- **`docs/`** is the amux.cc website + install scripts, not project docs.
  Root `Formula/amux.rb` is stale (v0.5.3); the tap formula is generated by the
  release workflow.
- Source is unusually comment-heavy (rationale / "why", not "what"). Match the
  density and voice of the file you edit. The project follows the user's global
  "no AI attribution in commits" rule.
- `CLAUDE.md` is an older architecture write-up; verify its details against the
  code (several are out of date).

## State & environment

- `~/.amux/` — `serve.pid`, `serve.log`, `amux.db`, `state/` (status snapshot +
  `events.ndjson`), `sessions.json`. The daemon's port is stored in the DB
  (`serve.port`), not the pid file.
- Some runtime artifacts are committed anyway — `output/mobile-uploads/`,
  `excalidraw.log`, `.DS_Store`; don't treat them as source or add more.
- `~/.config/amux/config.toml` (`$XDG_CONFIG_HOME` honored) — extra agents
- `~/.cc-switch/cc-switch.db` — provider database (`src/provider.rs`)
- `AMUX_DB_PATH`, `AMUX_STATE_DIR`, `AMUX_MUX`, `AGENT_MONITOR_TMUX_PATH`
  (legacy), `AGENT_MONITOR_STATE_DIR`, `CC_SWITCH_DB_PATH`,
  `CC_SWITCH_SETTINGS_PATH`, `CC_SWITCH_APP_PATH`, `CC_SWITCH_SKIP_RESTART`,
  `DEEPSEEK_API_KEY` / `DEEPSEEK_BASE_URL` / `DEEPSEEK_MODEL` (plus
  `AGENT_MONITOR_DEEPSEEK_*` variants), `AMUX_HERDR`, `AMUX_CRONBOX`,
  `AMUX_DSH_URL`, `AMUX_GITHUB_PROXY`, `AMUX_REGISTRY`, `AMUX_RMUX_VERSION`,
  `APNS_KEY_ID` / `APNS_TEAM_ID` / `APNS_KEY_PATH` / `APNS_BUNDLE_ID` / `APNS_ENV`
